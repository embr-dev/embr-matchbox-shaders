# embr-matchbox-shaders

Matchbox shaders for **Autodesk Flame**.

Part of **[Embr](https://github.com/embr-dev/Embr)** — tools and community resources for Flame, with a Japan-focused outlook.

## Status

Early setup. Shaders live under `shaders/`. Planned work: [`docs/planned/`](docs/planned/README.md).

## Creating shaders

Cursor / agent instructions and the Matchbox API reference are in [`docs/api/`](docs/api/README.md). Conventions: `embr_` prefix, classic GLSL, sidecar XML, MIT.
